被这个 return left 阴了一手，差点没做出来。其他的跟 704 差别不大。

> ### 🤖 AI 补充

<br>

循环退出时一定满足 `left == right + 1`，而且两边已经分好了：`left` 左边（含 `left-1`）全是 `< target`，`left` 及右边全是 `>= target`。所以 `left` 就是「第一个 >= target 的下标」，既是有序数组里唯一合理的插入点，也是 target 存在时它自己的位置。

三种情况都成立：

- target 比所有元素都小：`right` 一路减到 `-1`，`left` 停在 `0`
- target 比所有元素都大：`left` 一路加到 `n`，正好是末尾追加的位置，所以返回 `n` 是合法的，虽然它越界了
- 落在中间：`left` 停在第一个比 target 大的位置

也可以写 `return right + 1`（因为退出时两者差 1），但 `left` 的含义更直白。

和 704 的差别其实只有末尾那两行：找不到时不要提前 `return -1`，而是让循环跑完把 `left` 交出去。同一个二分，只是「没找到」从失败变成了答案。所以在 704 里可以把 `left` 想成 lower_bound 的返回值，`-1` 才是额外加的那层判断。

要小心的就是把 `return left` 顺手写成 `return right` 或 `return mid`——差一位，`right` 停在最后一个 `< target` 的位置，不是插入点。这就是刚才被阴的地方。
